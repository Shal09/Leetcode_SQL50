# Leetcode_SQL50 

**Happy Querying! 🚀**


Welcome to my repository of solutions to 50 SQL problems on LeetCode! This repository showcases my understanding of SQL concepts and my ability to solve real-world database problems effectively.

About the Repository
This repository contains solutions to SQL problems from LeetCode. Each solution is organized by problem name and difficulty level. These problems cover a variety of SQL topics, including:
Basic SQL Queries: Selecting data, filtering, sorting, and aggregation.
Joins: Combining data from multiple tables using INNER JOIN, LEFT JOIN, RIGHT JOIN, and FULL JOIN.
Subqueries: Using subqueries for complex filtering and calculations.
Window Functions: Leveraging ROW_NUMBER(), RANK(), NTILE(), etc.
Advanced Topics: Union, group by with having, self-joins, and more.
